# 验证记录

## 2026-10-05 当前开发版本 0.1.2

已移除历史版本浏览页面、组件、样式、文案、DTO、合约和后端读写接口。采集仅更新最新累计归档，不再保存采集前/后的完整副本；已有旧文件保持原样。

“最近新增”仍在监测卡面显示推荐/不推荐两项。统计由采集直接计算，保存在当前归档的 `last_new_counts` 中，每轮替换；排除旧评论修改、未知推荐状态及楼中楼。归档 schema 为 v3，插件版本仍为 0.1.2。v1/v2 在内存中兼容迁移，读取不改写文件；旧归档无统计时显示“—”，下次采集后更新。

回归覆盖：新增分类、第二轮归零、重启后持久化、旧归档兼容且不改写、遗留文件不被读取/覆盖且不产生新文件，以及调度时间与准入一致、暂停/运行中不显示到期时间、立即执行队列、设置保存与读取，以及采集取消/失败、独立楼中楼分页、增量停点、限速、暂停与恢复。协议测试使用本地 mock Core，检查已移除方法返回错误、当前归档查询与统计、启动调度及暂停/目标操作。

高级设置仍位于暂停/恢复旁，通过右侧 Sidebar 展示。周期输入为分钟，请求节流为毫秒。新配置默认每 30 分钟增量，已有配置不覆盖。保存时显示“正在保存…”并禁用重复提交；成功持续显示“已保存 / 设置已生效”，直到再次编辑；校验或保存失败时保留草稿并显示原因。保存后刷新状态，更新卡面上的下次时间。

卡面保留最近成功时间，并显示下次采集时间。后端由与任务准入相同的逻辑计算 `next_collect_at`，覆盖默认周期、冷却指数及上限、设置变更、首次采集和立即执行队列；已到期显示等待调度。暂停或运行中返回 null，界面显示暂停或采集中，不显示无效时间。监测指标保持同一行。添加监测仍仅在采集结果页提供。
